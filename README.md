Petbae is a pet matchmaking experience that helps people discover compatible pets and connect with trusted organizations. This is the first part of a larger vision to build an AI native Pet ownership operating system which covers all aspects of ownership.

## What This Product Does
Petbae provides a friendly, modern way to browse pets, understand compatibility, and start a conversation with a rescue or breeder without exposing sensitive systems or data.

## Key Features (High Level)
- AI-powered Pet discovery and recommendations tailored to user preferences
- Profile-based matching and simple messaging flow
- Safety and privacy-focused onboarding experience
- Admin tools for content and quality control providing CRM capablities

## High-Level Architecture
This product uses a Flutter mobile app, a lightweight API layer, and a managed database service. The public system design is documented in `docs/architecture.md`.
